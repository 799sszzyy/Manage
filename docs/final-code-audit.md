## 保留原因

- `docs/batch*`：保留批次验收和契约追踪依据。
- `third_party/QXlsx`：提供真实 `.xlsx` 能力，保留许可证和固定版本。
- `tests/e2e`：虽代码较长，但覆盖迁移、重启、权限、快照和持久化的外部链路，不属于重复测试。
