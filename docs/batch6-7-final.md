# Batch 6 + 7 最终交付范围

- 版本：v0.7.0
- 集成分支：`codex/batch6-7-final-v0.7.0-p18087`
- 验收端口：18087
- 正式默认端口：18080

## Batch 6：局域网运行

- 服务端默认仍绑定 `127.0.0.1`。
- 非本机监听必须同时提供 `--listen-address` 和 `--allow-lan`，防止误开放。
- 桌面端允许使用可信局域网内的 IPv4 地址或主机名。
- MySQL 仍只连接服务器本机，不向客户端或局域网直接开放。

## Batch 7：Windows 运维交付

- 生成包含 Qt、QMYSQL 和 MySQL 客户端运行库的时间戳运行包。
- 通过独立配置文件切换单机、服务器和客户端模式，配置样例不含密码。
- 提供服务端/桌面端启动脚本、数据库备份脚本和需要库名二次确认的恢复脚本。
- 提供用户说明书和开发说明书，最终 DOCX 必须通过逐页渲染检查。

## 验收原则

- 各改动只做一次针对性检查。
- 合并后只做一次 Release 总构建和一次完整 CTest。
- 使用 `_test` 独立数据库和端口 18087 完成一次说明书示例链路。
- 不删除用户数据库、永久分支或最终运行包。
