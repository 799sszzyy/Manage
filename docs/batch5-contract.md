# 第五批（Batch 5）共同契约

## 共同边界

- 固定版本 `v0.5.0`，并行验收端口 `18085`，正式默认端口仍为 `18080`。
- 不实现报价审核；不得修改 `draft -> issued -> void` 状态规则。
- 已发布报价的客户、物料与金额快照不得被用户管理、Excel 导入或统计功能改写。
- 数据库变更只能新增 `003_*.sql` 及更高版本，不得修改 001/002。
- 批量写入必须先完整校验，再在单个事务中提交；任一行错误时不得产生半批数据。

## 模块 1：用户与权限管理

- 仅 `admin` 可以查询和管理用户；`quoter`、`viewer` 返回 403。
- 支持分页/搜索、创建账号、修改显示名和角色、启用/停用、重置临时密码。
- 用户名创建后不可修改；密码仍使用现有 PBKDF2 规则。
- 禁止停用当前登录管理员，禁止停用或降级最后一个可用管理员。
- 重置后的账号必须在下次登录后修改临时密码。

## 模块 2：Excel/批量导入导出

- 使用真正的 `.xlsx`，不依赖本机安装 Microsoft Excel，不使用 COM 自动化。
- 物料模板列固定为：编码、名称、规格、单位、类别、当前单价、是否启用。
- 编码按现有记录更新，不存在时新建；空编码、重复编码、非法价格和非法状态必须报告行号。
- 单次导入最多 5000 行；导入前展示校验摘要，用户确认后才提交。
- 导出包含物料清单、单个 BOM、单个报价单和统计报表；金额单元格保存为数值并使用两位小数格式。
- 第三方工作簿库必须固定版本并携带许可证，构建与运行不依赖网络。

## 模块 3：统计分析

- 查询参数：开始日期、结束日期、可选客户和可选报价状态。
- 汇总字段：报价数、总金额、平均金额、已发布数、作废数、发布率。
- 明细维度：月份、客户和物料类别；金额以分从数据库聚合，JSON 仍返回整数分。
- 不把 `issued` 解释为成交成功；本批次不计算业务“成交成功率”。
- `admin`、`quoter` 可查看，`viewer` 只读查看；所有角色均不得通过统计接口修改数据。

## 模块 4：BOM 拖拽编辑

- 支持从物料选择区拖入当前 BOM，支持 BOM 行内部拖动排序。
- 重排后 `lineNo` 统一为 10、20、30……，数量、备注和物料 ID 不得错位。
- 拖入重复物料时合并数量，不生成重复行；无效拖放不修改界面。
- 保存仍复用现有 BOM API 与乐观锁，不新增另一套持久化逻辑。

## 整合责任

- 整合分支负责把四个 Widget 接入同一个主窗口，处理 CMake 和测试清单冲突。
- Excel 模块提供共享工作簿接口；统计模块只生成统计数据，统计 Excel 在整合阶段连接。
- 最终验收覆盖管理员创建报价员/查看员、物料导入导出、BOM 拖拽、报价导出、统计查询与统计导出。
