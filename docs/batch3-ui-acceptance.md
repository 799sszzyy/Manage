# 第三批（Batch 3）桌面业务界面验收

## 固定标号

- 批次：Batch 3
- 软件版本：v0.3.0
- 并行验收端口：18083
- 正式默认端口：18080
- 整合分支：`codex/batch3-ui-integration-v0.3.0-p18083`

`18083` 只用于第三批开发验收，正常安装运行仍使用 `18080`。

## 启动验收程序

先在已经设置好 `MANAGE_DB_*` 环境变量的 PowerShell 中启动服务端：

```powershell
.\build-local\Release\manage-server.exe --port 18083
```

再开一个 PowerShell 启动第三批桌面端：

```powershell
.\build-local\Release\manage-desktop.exe --api-url http://127.0.0.1:18083
```

## 手工验收顺序

1. 新数据库第一次启动时，在“首次初始化”页为 `admin` 设置临时密码。
2. 使用 `admin` 登录，并按提示把临时密码改成正式密码。
3. 在“客户与物料”页新增客户和物料，确认搜索、编辑、翻页及物料启停可用。
4. 在“BOM 与报价”页新建 BOM，选择物料并保存明细，确认再次打开仍能读取。
5. 选择 BOM，输入数量、运费、其他费用、加价率和税率，执行报价核算并检查金额结果。
6. 刷新当前用户并退出登录，确认受保护页面不再加载数据。

## 本批边界

第三批完成的是“登录后可以维护基础资料、BOM 并计算报价”的桌面闭环。报价核算结果目前不会保存到数据库，因此报价单编号、草稿/已发出/作废状态、历史记录、复制和导出仍属于后续批次，界面中会明确提示“本次计算不会保存”。
