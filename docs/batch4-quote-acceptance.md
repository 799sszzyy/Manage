# 第四批（Batch 4）报价生命周期验收计划

## 固定标号

- 批次：Batch 4
- 软件版本：v0.4.0
- 并行验收端口：18084
- 正式默认端口：18080
- 整合分支：`codex/batch4-quote-integration-v0.4.0-p18084`

本文件中的 `18084` 只用于开发验收，不改变正式运行默认端口。

## 自动化验收

1. Release 配置和编译成功。
2. 保持 Batch 1～3 的全部测试通过。
3. 报价数据测试覆盖事务、核算、快照、乐观锁、状态流转、复制和草稿删除。
4. 报价路由测试覆盖权限、JSON、HTTP 状态和全部生命周期动作。
5. 报价桌面测试覆盖管理员、报价员、查看员、临时密码和中文错误提示。

## 真实 MySQL 验收

必须创建名称以 `_test` 结尾的全新数据库，并在 `18084` 执行以下顺序：

1. 启动服务，确认 001 和 002 迁移完整执行。
2. 初始化管理员、登录并修改临时密码。
3. 创建客户、物料与 BOM。
4. 创建报价草稿，保存客户与物料快照并核对金额。
5. 重启服务，确认草稿仍可查询和修改。
6. 使用旧 `revision` 修改，确认返回 409；使用新版本修改成功。
7. 发布报价，确认内容被冻结且记录发布时间。
8. 修改原客户、物料名称和单价，再读取已发布报价，确认历史快照未改变。
9. 复制已发布报价，确认生成新编号、新草稿和 `sourceQuoteId`。
10. 作废原报价，确认只能查询和复制。
11. 新建另一个草稿并删除，确认详情返回 404；发布后的报价不能删除。
12. 使用查看员确认只能读取；使用报价员确认可以完成报价业务操作。

## 桌面手工验收

1. 报价列表能按关键词、状态和页码查询。
2. 详情页正确显示编号、客户快照、状态、费用、税率、合计和物料快照。
3. 新建与修改草稿时可选择客户、可选 BOM 和多条物料。
4. 发布、作废、复制、删除按钮只在合法状态和角色下启用。
5. 删除草稿前必须二次确认。
6. 409、403、断网和非法输入均显示可理解的中文信息。

## 第四批边界

第四批完成报价单的数据库生命周期，但不包含 Excel 导出、用户账号管理和统计报表。这三项保留给 Batch 5。
