# 版本与验收端口对照表

| 批次 | 软件版本 | 验收端口 | 正式默认端口 | 说明 |
| --- | --- | --- | --- | --- |
| Batch 1 | v0.1.0 | — | 18080 | 建立认证、目录和 BOM 等后端基础模块。 |
| Batch 2 | v0.2.0 | 18082 | 18080 | 接入业务权限、桌面 API 客户端和后端端到端验收；主提交为 `653cbd5`。 |
| Batch 3 | v0.3.0 | 18083 | 18080 | 接入桌面登录、客户/物料、BOM 与报价核算界面。 |

## 为什么验收端口不是正式默认端口

验收端口只用于开发过程中同时启动不同批次或不同分支，避免它们互相占用同一个端口。Batch 2 使用 `18082`，Batch 3 使用 `18083`，并不代表安装后的软件会改用这些端口。

正式运行时，服务端和桌面端仍默认使用 `127.0.0.1:18080`。只有执行并行验收时，才通过命令行参数临时指定对应的验收端口。

第三批的分支名称也固定带有 `batch3-v0.3.0-p18083` 含义，避免以后同时测试多个批次时混淆代码版本和端口。
