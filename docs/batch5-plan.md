# 第五批（Batch 5）实施计划

## 固定标号

- 批次：Batch 5
- 软件版本：v0.5.0
- 并行验收端口：18085
- 正式默认端口：18080
- 整合分支：`codex/batch5-integration-v0.5.0-p18085`

## 四个永久模块

1. 用户与权限管理：管理员创建、编辑、停用账号，分配 `admin`、`quoter`、`viewer` 角色并重置临时密码。
2. Excel/批量导入导出：物料批量导入导出、BOM 导出、报价单导出和统计报表导出，统一使用 `.xlsx`。
3. 统计分析：按时间、客户和报价状态查询数量与金额，显示客户和月份排行。
4. BOM 拖拽编辑：从物料区拖入 BOM、拖动调整顺序并自动重排 `lineNo`。

本批次明确不实现报价审核，不增加“待审核/已审核”状态。报价生命周期仍为 `draft -> issued -> void`，不实现多层 BOM。

## 验证策略

- 每个功能分支只执行一次 Release 针对性测试。
- 每合并一个模块执行一次相关回归，不做十次重复验证。
- 最终在名称以 `_test` 结尾的隔离数据库和端口 `18085` 完成一次完整验收。
- 验收成功后合并 `main`；四个功能分支和整合分支全部保留。
